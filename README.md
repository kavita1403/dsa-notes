# DSA Notes

Structured, pattern-first notes for SDE-2 interview prep — organized by *pattern*, not by individual problem, so they stay useful for revision long after the specific problem is forgotten.

## How to use this repo

- Each topic file follows the same skeleton: **When to use it → Template → Why this shape works → Edge cases → Common pitfalls → Example problems.**
- `cheatsheets/` holds the short, dense 1-pagers — pull these up the night before an interview instead of re-reading the full notes.
- Commit history doubles as a study log — every pitfall added or template revised is a timestamped record of what you actually learned and when.
